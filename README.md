# تحلیل فروش Superstore با Excel | Superstore Sales Analysis (Excel)

تحلیل و داشبورد تعاملی فروش یک فروشگاه زنجیره‌ای بر پایه ۵٬۴۹۶ سفارش، با استفاده از Pivot Table، انواع نمودار و اسلایسر در Microsoft Excel.

## درباره پروژه

این پروژه یک داشبورد چندصفحه‌ای برای تحلیل عملکرد فروش، سود و مرجوعی‌هاست. داده خام شامل اطلاعات سفارش (تاریخ، فروش، سود، تخفیف، منطقه، دسته محصول) و اطلاعات مرجوعی (Returns) بوده که با Pivot Table پردازش و در قالب چند نمودار مختلف نمایش داده شده.

## ساختار فایل

| شیت | توضیح |
|---|---|
| `Orders` | داده خام: ۵٬۴۹۶ سفارش با ۲۳ ستون (تاریخ، فروش، سود، مشتری، منطقه، دسته محصول و...) |
| `Returns` | لیست سفارش‌های مرجوعی |
| `Users` | نگاشت منطقه به مدیر مسئول |
| `Dashboard` | داشبورد اصلی با ۷ نمودار ترکیبی (خطی، دونات، ناحیه‌ای، میله‌ای) و ۳ اسلایسر تعاملی |
| `Monthly KPI` / `KPI YOY` | شاخص‌های کلیدی عملکرد ماهانه و مقایسه سال به سال |
| `Sales & Profit by Year` | روند فروش و سود سالانه |
| `Sales by Category` | سهم فروش به تفکیک دسته محصول |
| `Sales by State` | پراکندگی فروش در ۵۱ ایالت |
| `Profit by Category` | تحلیل سود به تفکیک دسته محصول |
| `Top 5 Subcategories` | پرفروش‌ترین زیر‌دسته‌های محصول |

## تکنیک‌های استفاده‌شده

- **Pivot Table** با یک Pivot Cache مشترک برای ۱۱ جدول (کاهش حجم فایل و رفرش یکپارچه)
- **GETPIVOTDATA** برای اتصال پایدار کارت‌های KPI به داده Pivot
- **اسلایسر (Slicer)** برای فیلتر تعاملی روی داشبورد
- ترکیب چند نوع نمودار (خطی، دایره‌ای/دونات، میله‌ای، ناحیه‌ای، آبشاری، نقشه) متناسب با نوع سوال تحلیلی

## یافته‌های کلیدی

- از مجموع ۹٫۷ میلیون دلار فروش، سود کل ۱٫۱۶ میلیون دلار بوده که معادل حاشیه سود ۱۱٫۹٪ است.
- منطقه **Central** با ۳۶۴ هزار دلار بیشترین سود را داشته، در حالی که بیشترین فروش هم متعلق به همین منطقه است (۳ میلیون دلار) - یعنی این منطقه هم از نظر حجم و هم از نظر سودآوری در رتبه اول است.
- دسته محصول **Technology** با فروش ۳٫۷۶ میلیون دلار بیشترین فروش را دارد، اما نکته مهم‌تر این‌ است که با سود ۶۱۶ هزار دلار، **سودآورترین** دسته هم همین است؛ در مقابل **Furniture** با فروش نزدیک (۳٫۲۶ میلیون دلار) فقط ۱۰۷ هزار دلار سود ساخته - یعنی حاشیه سود این دو دسته بسیار متفاوت است.
- زیر‌دسته **Office Machines** با ۱٫۴۷ میلیون دلار پرفروش‌ترین زیرمجموعه محصولات است.
- نرخ کلی مرجوعی سفارش‌ها ۱۰٫۴٪ است (۵۷۲ سفارش از ۵٬۴۹۶ سفارش). دسته **Furniture** با نرخ مرجوعی ۱۱٫۲٪ بیشترین نرخ برگشت را دارد که با توجه به حاشیه سود پایین همین دسته، نشان می‌دهد Furniture نیازمند بررسی بیشتر (کیفیت محصول یا دقت توضیحات فروش) است.
- روند فروش سالانه (۲۰۰۹ تا ۲۰۱۲) نسبتاً باثبات بوده و نوسان شدیدی نداشته، با بیشترین فروش در سال ۲۰۰۹ (۲٫۶۵ میلیون دلار).
